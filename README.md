# wavingui

The interface layer every WavingEye product shares: theme, tokens, fonts,
components, the rules that bound them, and the gallery that proves them. Brand
identity and the colour contract live in
[wavingbrand](https://github.com/SebiShepherd/wavingbrand); this repository
builds on them.

Nothing is built yet. The work follows
[kagami](https://github.com/SebiShepherd/kagami)'s loop, and it is at the spec:

- [`docs/research/outward.md`](docs/research/outward.md): what the reference kits do
- [`docs/research/inward.md`](docs/research/inward.md): what Hikaru, the seed, has today
- [`docs/specs/0001-the-kit.md`](docs/specs/0001-the-kit.md): what v1 is, awaiting review
